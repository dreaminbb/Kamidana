# Contributing

Thanks for considering a contribution. This project is still under active development (currently ~60% toward v1.0), so expect some rough edges — that's part of why we're looking for collaborators.

## Getting Started

1. Fork the repository and clone it locally.
2. Check the [Issues](../../issues) tab for tasks labeled `good first issue` or `help wanted`.
3. Comment on an issue before starting work, to avoid duplicate effort.
4. Open a pull request against `main` (or the relevant branch) when ready.

## Code Style

- Follow the existing formatting and naming conventions in the codebase.
- Keep pull requests focused — one feature or fix per PR.
- Include a short description of *what* changed and *why*.

## Use of AI Tools

AI coding assistants (Copilot, ChatGPT, Claude, etc.) are welcome, but with conditions:

- **You must understand every line you submit.** If you can't explain why a piece of code works, don't submit it.
- **Don't paste AI output wholesale.** Use AI to draft, then review, test, and edit it yourself before opening a PR.
- **You are responsible for correctness.** AI-generated code is not a defense for bugs, security issues, or license violations — the reviewer will treat it the same as hand-written code.
- **Disclose significant AI involvement.** If a large portion of a PR was AI-generated, mention it in the PR description. This isn't a penalty — it just helps reviewers focus their attention.
- **No unreviewed bulk generation.** Don't use AI to auto-generate entire modules or large refactors without discussing the approach in an issue first.

## Pull Request Review

- PRs are reviewed for correctness, clarity, and fit with the project's direction.
- Be open to feedback and revision requests — this is a collaborative project, not a one-shot submission.
- Small, incremental PRs get reviewed faster than large ones.

## Communication

- Use Issues for bug reports, feature requests, and task discussion.
- Be respectful and constructive. Disagreements about approach are fine; personal attacks are not.
